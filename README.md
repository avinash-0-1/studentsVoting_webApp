# Student Voting Web Application

A secure **Student Voting Web Application** built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. The platform allows universities to conduct student elections digitally with transparency and fairness.

Students can log in using their **Student ID and password**, view the list of candidates, and cast their vote. Each student is allowed to vote only once to prevent duplicate voting. The system also displays the **live vote count** for candidates.

An **Admin panel** is included to manage the election process, such as adding, updating, or removing candidates. Admin users cannot participate in voting, ensuring neutrality in the election system.

---

## Features

- Student authentication using **Student ID**
- Secure **login and registration system**
- View list of election candidates
- **One student → one vote**
- Real-time **vote count display**
- Admin panel to **manage candidates**
- Secure backend APIs
